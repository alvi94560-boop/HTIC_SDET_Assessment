# BUG-001 - Checkout Can Be Completed With an Empty Cart

Defect ID: BUG-001

Linked Test Case: TC_CART_008

Target Feature: FEAT-CART

Severity: High

Priority: High

## Defect Summary

The application allows a user to proceed through the checkout flow and successfully complete an order when the shopping cart contains no products.

## Pre-condition

- User is logged in as `standard_user`.
- Shopping cart is empty.

## Steps to Reproduce

1. Log in as `standard_user`.
2. Navigate directly to the shopping cart.
3. Verify that the cart contains no products.
4. Click `Checkout`.
5. Enter a valid first name.
6. Enter a valid last name.
7. Enter a valid postal code.
8. Click `Continue`.
9. Observe the checkout overview.
10. Click `Finish`.

## Expected Result

The application should prevent checkout when the cart is empty and should not allow an order to be completed without any products.

## Actual Result

The application allows the user to proceed through checkout and successfully complete an order even though the cart is empty.
